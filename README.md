# Rogue-like Game

A simple graphical **Rogue-like game** developed in **C** using the **ncurses** library as part of the Programming Fundamentals course project at **Sharif University of Technology**.

## Overview

This project is the **first phase** of a Rogue-like game inspired by the classic *Rogue* genre.

The main focus of this phase is implementing the fundamental game systems, including user management, game menus, dungeon exploration, procedural map generation, player movement, collectible items, and game progression.

The game is designed with extensibility in mind, allowing additional gameplay mechanics and features to be introduced in future phases.

## Features

### 👤 User System

* User registration and login
* Guest access
* Username, password, and email validation
* Persistent user data

### 🎮 Game Menus

* User registration and login menus
* Pre-game menu
* New game
* Continue saved games
* Profile
* Leaderboard
* Game settings

### 🗺️ Dungeon & Map

* Procedurally generated dungeon maps
* Multiple rooms connected through doors and corridors
* Randomized room layouts
* Multiple dungeon floors
* Exploration and visibility mechanics
* Special map elements such as stairs and traps

### 🧭 Player Movement

* 8-directional movement
* Collision handling
* Movement through rooms and corridors
* Exploration-based map visibility
* Additional movement and search mechanics

### 💰 Items & Collectibles

The game includes several collectible elements:

* Gold
* Food
* Weapons
* Spells
* Special items and map elements

Items can be discovered throughout the dungeon and collected during exploration.


### 🏆 Leaderboard

The game includes a leaderboard system for comparing player performance.

Player rankings are based on their progress and collected resources, with additional information displayed for each player.

### 🏁 Game Progression

The objective is to explore the dungeon, collect resources, progress through its floors, and ultimately reach the treasure room.

The first phase focuses primarily on the core exploration and game systems, while more advanced gameplay mechanics are intended for subsequent phases.
